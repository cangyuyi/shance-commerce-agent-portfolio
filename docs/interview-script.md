# 面试讲稿

## 30 秒

我做了一个电商营销内容 Agent，用来解决大模型文案事实容易出错、品牌规则难复用、版本效果无法比较的问题。我把一次生成拆成结构化、检索、生成、事实与合规检查和人工确认五步，并建立了 20 条离线评测集和 7 项指标。当前公开版只使用脱敏和虚构数据，没有把离线结果包装成 GMV 或转化提升。

## 2 分钟

1. **场景：**我过去接触过电商内容和 AI 生成，但发现“能生成”不等于“能稳定交付”。
2. **问题：**单次 Prompt 会补写产地、功效、销量，也容易遗漏核心卖点；团队缺少统一验收标准。
3. **方案：**我将流程拆成 Brief 结构化、知识检索、生成、双重质检和人工确认，并要求关键事实映射到证据。
4. **评测：**我自建 20 条脱敏/虚构案例，覆盖缺失、冲突、违规、语气和格式问题，使用同一数据对比三个版本。
5. **取舍：**确定性风险先用规则拦截，品牌语气再做人评或模型辅助；MVP 不做复杂向量库。
6. **边界：**现在的数据只验证产品和评测方法，接入真实模型后需要复跑，线上商业价值还要通过采用率、审核耗时和 A/B 测试验证。

## 5 分钟追问

### 为什么用 Agent 而不是一个 Prompt？

因为错误需要归因。单个 Prompt 无法区分输入缺失、检索错误、生成幻觉和检查失败，也很难设计人工接管。

### 如何防止 LLM Judge 自说自话？

事实、格式和风险词使用确定性规则；主观指标先制定评分量表，由人工标注，再用 LLM Judge 辅助并校准一致性。

### 为什么没有真实业务数据？

这是个人探索项目，我没有使用公司内部数据，也不把离线分数包装成转化率。公开版证明的是问题拆解、产品设计、评测和迭代能力。

### 如果真实上线，第一项线上指标是什么？

先看内容一次审核通过率和平均人工修改时长，再看内容采用率；GMV和转化受到流量、价格、商品等因素影响，不能直接归因给文案 Agent。

### 最大风险是什么？

输入商品事实本身错误时，Agent可能“忠实地生成错误内容”。因此真实产品必须增加数据来源、更新时间和责任人，并保留人工发布责任。
