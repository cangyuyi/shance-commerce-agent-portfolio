# PRD｜商策 Agent

## 一、产品概述

商策 Agent 面向电商内容运营、品牌营销和 AI 内容制作人员，将商品事实、品牌规范和营销目标转化为可核验的营销内容，并通过统一评测集支持版本验收和 Bad Case 归因。

当前版本为个人作品集公开演示，不接入真实商家内部数据，不代表线上商业结果。

## 二、问题定义

### 用户任务

快速生成可以进入人工审核的商品营销内容。

### 当前痛点

1. 单次 Prompt 容易补写不存在的商品事实。
2. 品牌语气和合规要求缺少稳定执行。
3. 不同 Prompt 或模型版本无法使用同一标准比较。
4. 发现错误后只能整段重写，无法定位根因。

### 目标

- 让每条关键事实能追溯到结构化输入或知识条目。
- 让高风险内容优先由确定性规则拦截。
- 让 V0/V1/V2 使用同一评测集比较。
- 让低置信度或高风险任务回到人工确认。

### 非目标

- 不承诺提升 GMV 或转化率。
- 不训练和微调模型。
- 不在 MVP 阶段覆盖全部电商品类。
- 不替代企业法务、质检和最终内容负责人。

## 三、核心用户

| 用户 | 任务 | 成功标准 |
|---|---|---|
| 内容运营 | 生成并修改商品文案 | 更快进入可审核状态 |
| 品牌营销 | 保持品牌调性 | 减少明显跑调 |
| 产品/算法团队 | 验收版本 | 指标统一、结果可回查 |

## 四、核心流程

`输入校验 → Brief结构化 → 知识检索 → 内容生成 → 事实检查 → 合规/品牌检查 → 人工确认`

## 五、功能需求

### P0

- 商品输入 Schema
- 结构化内容输出
- 证据映射
- 禁止词和功效声明拦截
- 三版本评测
- Bad Case 记录

### P1

- 模型 API 接入
- Prompt 版本管理
- 结果导出
- 人工评分界面

### P2

- 线上反馈回流
- 多品牌知识空间
- 权限和审计记录

## 六、成功指标

- 事实准确性
- 卖点覆盖率
- 合规风险识别率
- 品牌一致性
- 输出格式通过率
- 工作流成功率
- 响应时延和成本

线上真实业务验证后才增加点击率、转化率、内容采用率和人工审核耗时。

## 七、风险

- LLM Judge 偏好与人工判断不一致。
- 检索命中但最终输出仍然失真。
- 合规规则遗漏或更新不及时。
- 用户输入本身错误，导致“忠实但不真实”的结果。

## 八、发布边界

公开版全部使用脱敏/虚构案例；不公开 API Key、客户资料、内部 Prompt、真实订单和个人敏感信息。
